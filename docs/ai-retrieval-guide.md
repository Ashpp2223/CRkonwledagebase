# AI 检索指南

查询顺序：问题 → 技术专题 → 项目 ID → 项目卡 → 原始来源 → 版本和证据。

输出应包含：哪些项目声称实现了目标功能；实现路线的差异；哪些已复核；哪些只在旧客户端适用；哪些功能仍未知；可直接追踪的源码或文档链接。

## 常见混淆
- 原生战斗引擎和独立重写的模拟器不是同一类实现。
- 导入出牌日志得到的“相容重建”不代表还原原始随机数及所有隐藏状态。
- 内存偏移对应的是确定的客户端构建；一个版本可用不代表新版本可用。
- `reset/step` 环境不一定支持廉价、可并发的任意状态克隆。
- 没有许可证文件不能推断作者授权代码复用。

重要回答应直接附上源仓库链接，并明确当前知识卡仅为作者文档整理还是经过独立验证。
