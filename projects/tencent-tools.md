# Tencent Overlay 与 Model Harness

**原仓库**：[ak1NaN/ClashRoyale-tencent-model-harness](https://github.com/ak1NaN/ClashRoyale-tencent-model-harness)。**初次整理**：2026-10-13。仅依据公开作者文档，尚未得到原作者审核，也未独立测试。

## 公开描述的能力

Tencent Model Harness 将腾讯客户端读取状态转换为 FirstLight V4 输入，输出动作与回执；配套 Overlay 提供部署队列与网格展示。

## 兼容与限制

Overlay 旧偏移据其 README 已在腾讯 38.4.2 失效；两个仓库各自版本与权限要求必须分开核验。
