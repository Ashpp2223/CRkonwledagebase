# SC Downloader GUI

**原仓库**：[Darknighture/sc-downloader-gui](https://github.com/Darknighture/sc-downloader-gui)。**初次整理**：2026-10-13。仅依据公开作者文档，尚未得到原作者审核，也未独立测试。

## 公开描述的能力

图形化下载 Supercell 资源，支持 Masterhash/Fingerprint、按类型下载、断点补齐、可选压缩格式解码。

## 兼容与限制

README 指出皇室战争 Latest Patch 握手当前不可用；仍需现成 Masterhash/Fingerprint。
