# crforge

**原仓库**：[voonhous/crforge](https://github.com/voonhous/crforge)。**初次整理**：2026-10-13。仅依据公开作者文档，尚未得到原作者审核，也未独立测试。

## 公开描述的能力

Java 确定性 Tick 模拟器，使用 ECS 风格实体与系统、JSON 驱动卡牌、LibGDX 调试界面和 ZMQ/Gymnasium 桥接。

## 兼容与限制

卡牌数值和特殊机制的完整覆盖不等于全部官方逻辑一致。
